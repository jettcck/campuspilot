# CampusPilot 用户手册

本手册面向使用 CampusPilot 的在校学生，介绍每个功能的操作方式。

---

## 一、注册与登录

1. 打开站点，进入登录页。
2. 首次使用切换到「注册」标签，填写用户名、邮箱、密码（至少 6 位），可选填学校、专业、年级。
3. 提交后自动登录并进入工作台。

已有账号直接在「登录」标签输入邮箱与密码即可。页面下方提供演示账号按钮，一键填入：

```text
demo@campuspilot.dev / Demo123456
```

登录状态保存在浏览器本地，关闭页面后重新打开无需重复登录。Token 有效期为 7 天。

---

## 二、总览页

登录后的默认页面，展示四块内容：

- **统计卡片**：本周学习时长（已完成任务时长累计）、任务完成率、连续学习天数与完成率环形图
- **今日任务**：直接勾选复选框即可标记完成，数据会实时同步到服务器
- **专注趋势**：最近 7 天每天完成任务的时长柱状图，最高的一天高亮显示
- **我的课程**：本学期课程与进度条

右上角「新建任务」按钮可以快速添加任务，会弹出输入框填写任务名称。

页面右下角的 AI 卡片可以直接提问，回车发送，也可以点击「进入 AI 学习室」使用完整功能。

---

## 三、学习计划

### 用 AI 生成计划

1. 进入「学习计划」页。
2. 在输入框中写下目标，例如「两周内掌握 React 基础并完成一个项目」。
3. 选择天数（3 / 5 / 7 / 14 / 21 天）。
4. 点击「生成计划」。

系统会把目标拆解成按天推进的步骤，每一步包含标题、建议时长和一句话要点，并自动保存到「我的学习计划」。

### 使用计划

- 每完成一步，点击左侧方框勾选，进度条会实时更新
- 全部步骤完成后计划状态自动变为「已完成」
- 计划右上角可以删除不再需要的计划

右侧「全部任务」面板可以统一管理所有任务，包括删除操作。

---

## 四、课程资料

### 添加课程

在页面顶部表单填写课程名称、任课教师、下次上课时间，选择颜色标签后点击「添加课程」。颜色会应用在课程卡片、进度条和总览页上。

### 上传资料

1. 点击「上传资料」按钮选择文件。
2. 支持 PDF、Word、PPT、图片、文本、Markdown、ZIP，单文件不超过 10MB。
3. 如果先点击了某门课程卡片，上传的资料会自动归到该课程下。

### 使用 AI 摘要

每份资料右侧有「AI 摘要」按钮，点击后会调用 AI 服务生成结构化摘要，包含核心概念、关键结论与易错点，结果直接显示在文件下方，之后再次打开仍然可见。

「查看」按钮会在新标签页打开原始文件，「删除」会同时移除记录与物理文件。

---

## 五、AI 学习室

页面分为左侧工作区与右侧历史记录。

### 三种场景

| 场景 | 用途 | 输入示例 |
| --- | --- | --- |
| 学习问答 | 解释概念、给学习建议 | 数据结构里哈希冲突怎么处理？ |
| 资料总结 | 把长文本压缩成要点 | 粘贴一段课件内容 |
| 生成自测题 | 根据知识点出题 | 操作系统的进程调度 |

输入内容后点击「发送 ⌘+Enter」（也可以按 Ctrl / ⌘ + Enter）。

### 学习建议

点击右上角「生成学习建议」，系统会读取你的任务完成率、连续学习天数等数据，给出 3 条可执行的改进建议。

### 历史记录

每一次问答都会自动保存，右上角标签区分场景类型，方便回顾之前的提问。

> 说明：未配置模型 API Key 时，AI 输出由内置规则引擎生成，结构与真实模型一致，用于保证功能完整可演示。配置 `AI_API_KEY` 后即可自动切换为真实模型。

## 六、协作小组

### 创建小组

1. 进入「协作小组」页。
2. 填写小组名称与目标说明。
3. 点击「创建小组」。
4. 创建成功后卡片上会显示 6 位邀请码，把它发给组员。

### 加入小组

在右侧表单输入组员分享的邀请码，点击「加入小组」。

### 成员管理

小组卡片下方会显示所有成员头像与人数。组长（创建者）的卡片上带有「组长」标识，并且拥有「解散小组」权限。

---

## 七、校园信息

页面顶部提供分类筛选：全部、讲座、比赛、通知、活动。

每条信息显示分类标签、发布日期、标题、正文和来源单位。默认按发布时间倒序排列。

---

## 八、个人中心

- **基本资料**：修改用户名、学校、专业、年级，保存后立即生效
- **账号安全**：邮箱只读展示；修改密码需要输入原密码，新密码至少 6 位

修改密码成功后会自动退出登录，使用新密码重新登录即可。

## 九、常见问题

**Q：勾选任务后刷新页面，状态还在吗？**
在。任务状态会立即写入后端存储。

**Q：上传的文件存在哪里？**
默认存储在服务器的 `uploads/` 目录下，通过 `/uploads/xxx` 访问。

**Q：为什么 AI 回复比较模板化？**
说明当前未配置模型 API Key，使用的是内置规则引擎。在 `.env` 中配置 `AI_API_KEY` 并重启服务即可切换。

**Q：数据会丢吗？**
未配置 `MONGODB_URI` 时数据保存在 `server/data/db.json`；使用 Docker 部署时保存在名为 `appdata` 的数据卷中。请勿执行 `docker compose down -v`。

**Q：忘记密码怎么办？**
当前版本请在个人中心使用原密码修改；若完全遗忘，可由管理员在数据库中重置 `passwordHash` 字段。
